# Reinforcement Learning-Based Cryptocurrency Trading Strategy

CS5998 Capstone Project — Index 258743R

A Deep Q-Network (DQN) agent trained to make buy/hold/sell decisions on BTC/USDT
hourly candlestick data, benchmarked against Buy-and-Hold and Moving Average Crossover baselines.

---

## Quick Start — Reproducibility Check

The `reproduce.sh` script runs the full pipeline end-to-end on a fresh clone:
verifying data, installing dependencies, running all unit tests, processing data,
executing all notebooks, and confirming the final evaluation metrics.

```bash
# 1. Clone the repository
git clone <repo-url>
cd reinforcement-based-cryptocurrency-trading-strategy

# 2. Run the reproducibility script
bash reproduce.sh
```

**The script automatically extracts the bundled raw data from `data/zipped/1h.zip`** —
no manual download is needed. If the zip is missing or you want to use your own data,
download the 36 monthly BTC/USDT 1h CSV files from Binance Vision and place them in
`data/raw/1h/`:

```
https://data.binance.vision/?prefix=data/spot/monthly/klines/BTCUSDT/1h/
```

Files needed: `BTCUSDT-1h-2022-01.csv` through `BTCUSDT-1h-2024-12.csv`

### What the script does

| Step | Description |
| ---- | ----------- |
| 1 | Checks `data/raw/1h/` for 36 CSV files; auto-extracts from `data/zipped/1h.zip` if missing |
| 2 | Creates `.venv/`, installs all dependencies from `requirements.txt` |
| 3 | Runs all 56 unit tests via `pytest` |
| 4 | Runs `python -m src.data.pipeline` to produce processed, feature, and normalised splits |
| 5 | Executes all 5 Jupyter notebooks in order |
| 6 | Verifies `models/best/best_model.zip` exists and prints the final test metrics table |

> **Note:** Step 5 includes notebook 04 (training analysis) which will display a
> skip message for the learning curve if no training log exists — this is expected
> on a fresh clone since the pre-trained model is used directly.

## Manual Setup

If you prefer to run steps individually:

```bash
# Create and activate virtual environment (Python 3.12)
python3.12 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Extract raw data
unzip data/zipped/1h.zip -d data/raw/

# Run the data pipeline
python -m src.data.pipeline

# Run unit tests
pytest tests/

# Train the DQN agent (optional — pre-trained model is included)
python -m src.training.trainer

# Run evaluation
# Open and execute notebooks/v2/05_results_analysis.ipynb
```

## Data

- **Source:** Binance Vision — BTC/USDT hourly (1h) candlestick data
- **Train:** Jan 2022 – Aug 2024 (23,326 rows after 49-row warm-up drop)
- **Val:** Sep 2024 (720 rows) — used for early stopping during training
- **Test:** Oct – Dec 2024 (2,208 rows) — held-out evaluation set

---

## Key Results (Test Set — Oct–Dec 2024)

| Metric | Buy-and-Hold | MA Crossover | DQN (V3) |
| ------ | ------------ | ------------ | -------- |
| Total Return | +47.29% | +34.57% | +29.74% |
| Max Drawdown | −15.13% | −13.30% | −8.27% |
| Sharpe Ratio | 3.28 | 3.29 | **3.79** |
| Sortino Ratio | 4.40 | 3.51 | 3.68 |
| Calmar Ratio | 24.14 | 16.91 | 21.90 |

The DQN achieves the best risk-adjusted return (Sharpe 3.79) and lowest drawdown (−8.27%)
despite a lower raw return — consistent with its conservative, risk-managed trading style.
